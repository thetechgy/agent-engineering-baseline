How to read the measures

Evaluator-reported (native) metrics use the evaluator's original score units. Skill Lift is its with-minus-without difference. Grading criteria (rubric) and mandatory checks (gates) record separate outcomes. Values are preserved, not recomputed from rounded case scores. Case deltas use descriptive arm means only where all planned attempts are scored. A positive delta is higher, a negative delta is lower; neither explains why. Mandatory gates are separate from rubric passes. Unknown counts, scores and gates stay unknown.
